# 数据来源、授权与参考

## 一手来源

1. [Olist 官方营销分析挑战仓库](https://github.com/olist/work-at-olist-marketing)——给出营销漏斗案例背景和原始任务入口。本作品不是该公司的当前招聘测试。
2. [Marketing Funnel by Olist](https://www.kaggle.com/datasets/olistbr/marketing-funnel-olist)——MQL 与 closed deals 数据来源。
3. [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)——商家、订单和订单商品数据来源；公开样本约 10 万订单。
4. [Creative Commons BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)——Kaggle 数据页标注的原数据授权条款。原始数据不在本仓库重新分发。

## 展示设计参考

- [Brazilian E-Commerce 数据集的公开 Code 页面](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce/code)仅用于观察公开作品常见的信息组织方式；本仓库没有复制某个 notebook 的代码、图表或结论。
- 页面视觉、指标口径、Python/SQLite 实现与文字均围绕本案例重新设计；所有公开数字由本仓库脚本从上面的一手数据复算。

## 归因和真实性说明

- “Olist”是数据提供方，不是本人的实习单位或客户。
- 数据是匿名公开样本，结论只适用于这些文件和本项目定义的窗口。
- 本项目使用 Codex 协助研究、编码和页面制作；AI 的参与已在 README 明示。最终口径、验证、限制和面试表达需要由本人理解并负责。
