# 简历作品集候选表述

## 一页简历版本

**Olist电商获客质量与商家运营分析｜pandas、SQLite、HTML/CSS/JavaScript**

- 基于8,000条营销线索及成交、商家、订单、商品明细五表，统一MQL与商家分析粒度，构建首次接触后90天可观测价值链路；处理多商品/多商家订单、日期异常和不可观测样本。
- 使用pandas生成渠道与商家指标，并以SQLite从原始五表独立重算；核验842个成交商家中379个进入运营合格组，245个激活、134个未激活，样本内1,693个商家订单及R$261,665.04商品GMV。
- 基于激活与贡献集中度提出“数据核验—未激活商家试点—已激活商家经营支持”方案，明确核心/保护指标和继续/停止规则；试点尚未执行，不将GMV表述为利润或ROI。
